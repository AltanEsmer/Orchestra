# Collection brief for the main comparison

Prepared October 22, 2026, before any research model errors exist. `prepare-study` records this file's hash before the M2 split. Freeze that copy for the expansion; document later changes before collecting affected rows.

Use human-authored English queries about fictional situations and the four first-action definitions in the annotation guide. Target 400 accepted rows, roughly 100 per class. This is a collection target, not a result. The first 120 accepted rows retain their text, labels, group IDs, and split memberships.

Include varied request styles and wording lengths. Cover direct instructions, questions, negation, retrieval-before-calculation dependencies, and the documented action boundaries. Include at least two independently authored scenarios for each boundary. Avoid a single trigger word that identifies one label. A requested stable fact without a named source follows the current direct-answer rule.

New main-study rows must belong to independent scenario families. Compare candidates with existing families before allocation. Related variants belong with their original family and cannot be added as new independent test groups. Keep at most four rows per family. Related additions to frozen families belong in a separate challenge collection.

Apply the same permission, human rationale, and blind-review requirements to additions. Review at least 20 percent per class, all ambiguous cases, and mixed-label groups. Record exclusions and unresolved boundaries. Do not collect new test candidates to target mistakes seen in M2. Do not add external corpora or generated candidates without changing and recording the collection protocol.

The agent measures class/group counts, word lengths, source mix, agreement, and exclusions after collection. Those observations establish achieved coverage. This brief cannot guarantee natural user language or real-world routing performance.
