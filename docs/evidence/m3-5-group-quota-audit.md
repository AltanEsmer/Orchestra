# M3.5 independent-group and quota audit

October 31, 2026, following the [initial screen](m3-5-capacity-screen.md). Altan asked to continue checking independent groups and source quotas, prioritizing varied lookup and calculation queries toward **2,500 minimum and 4,000 preferred**. The accepted release remains **400 rows in 360 groups**. No source was adopted, label accepted, split changed or model trained.

The integrated conservative inventory now contains **99 provisional calculation rows in 69 proposed groups** and **46 provisional lookup rows in 37 proposed groups**. These combine retained earlier candidates and new investigations; they are not all newly discovered or accepted. Group IDs are screening proposals, not certified independent research groups. Source/adapter, semantic collision and human-review checks can reduce these counts.

The main remaining constraint is quantitative: the 625-per-class target needs **315 additional non-keyed lookups**, while the inspected inventory currently provides **11**. Calculation needs **291 additional non-word-problem rows**, while the inspected inventory provides **57**. More eligible material may exist outside these bounded screens; these are inventory gaps, not population impossibility claims.

## Audit the earlier candidates

The earlier sampled calculation proposals contained 68 records, reduced to 63 normalized-exact unique strings. Five exact repeats, twelve conservative parent-pattern holds and four new semantic-review holds leave **47 calculation candidates in 44 proposed groups**. The lookup proposals contained 34 records: three exact repeats, three parent-profile holds and four over-cap movie variants leave **24 candidates in 20 proposed groups**. Earlier evidence stays unchanged; this is a new audit layer.

Kept every pair edge, exclusion and rationale. Exact text and number-swap skeletons are reproducible checks. Token overlap at least 0.5 is a flag for manual interpretation, not automatic proof of identity. For example, session records and manager records can use the same placeholder IDs without sharing a source. A recipe request and a profile request also share boilerplate without describing the same record. Those false lexical links were rejected explicitly. A long fireworks-shopping scenario was not merged with a simple product-discount query solely because both use a discount.

BMI, simple rectangle-area, factorial, product-discount and profile-ID patterns retain conservative parent holds where their shared-scenario status is unresolved. These are not claims that all instances of one mathematical operation belong to one group. New semantic holds include ambiguous Fibonacci bounds, a contradictory date premise, an infinite solution-class boundary and a missing geographic distance model. No parent row/group was corrected or moved.

The [calculation investigation](m3-5-calculation-diversity.md) judged **120 Math Stack Exchange question bodies** and **100 existing published synthetic prompts**. Independently posted questions yielded 12 provisional rows in eight tentative groups; one congruence-system case is additionally held in the integrated inventory because it asks for an infinite solution class. The synthetic sample yielded 96 numeric proposals, 64 after its own provisional template caps. Integrating all pair links and parent-pattern holds reduces its contribution further to 39. Public generated language is disclosed; no new examples were generated.

The Math Stack Exchange snapshots retain post-specific licenses, authors, revision GUIDs, dates and exact body hashes. HTML-to-text projection requires an adapter decision. Quoted exercises and source reuse still need review; platform licensing metadata is not proof that a poster owned every quoted question. The small synthetic benchmark's author explicitly scopes MIT to the code and synthetic portion; translated competition records were excluded before sampling. MATH and MathOdyssey add **zero cleared capacity**, because the investigation found a rights dispute for MATH and a test-only restriction for Odyssey. The linked note contains primary sources and exact access history.

An additional check of adopted human-written corpora screened **31 Dolly instructions** (the complete digit-plus-computation-keyword pool with no separate context) and **60 of 321 No Robots train prompts** using a fixed seed-42 order. Dolly yielded one explicit linear substitution and two identical rabbit/duck word problems: **two distinct candidates**. Seven were held and 21 were not calculation requests. No Robots yielded zero conservative calculation candidates: 57 main requests were explanations, writing, classification or passage work, and three were held. Long passage excerpts were inspected for the requested action rather than treated as full content audits. This 91-decision screen shows that words such as “sum”, “convert” and “average” frequently appear in non-calculation requests.

Together these follow-ups record **773 formal screening decisions**, separate from the earlier 630. Counts include repeated/source-overlapping records and are not unique queries. A further 100 MATH positions have rights-hold records, not route judgments, and are excluded from 773.

## Integrated inventory and remaining gaps

Combine exact source-row identities, normalized text, prior group hints, number-swap skeletons and reviewed pair flags across all candidate bundles. Retain immutable source projections and provenance; normalize only for comparison. The integration found no cross-source exact or token-overlap-at-least-0.5 pair among its proposed input rows. This cannot rule out semantic or quoted-source overlap.

Within the synthetic benchmark, common numerical instruction formats connect several initially separate template clusters. The conservative connected components are capped at four; this prevents multiplying essentially repeated prompts into apparent supply. Mathematical operators and actual scenarios still need human examination: lexical token sets discard punctuation, so these components can over-merge different tasks. They are an explicitly conservative working inventory, **not a mathematical upper bound on true independent capacity**. Source-template hypotheses, rejected lexical links and parent holds remain visible in the audit.

No relaxation, synthetic padding or replacement of old split groups is authorized by this audit.
