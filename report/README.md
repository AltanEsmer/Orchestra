# Write the final report

`main.tex` uses IEEEtran conference format and contains author prompts. The Codex desktop compiler successfully compiled this template on October 22, 2026. It is not the final report and has no research results or verified final page count.

Open this directory in Codex for a source editor and PDF preview. Replace the prompts with your own account after the saved experiments exist. Keep the final report within the course's 5-12 page limit. Check the compiled PDF's actual pagination and every figure before submission.

The agent supplies measured tables from `results/m3-a-report/comparison.md`, figure exports and source hashes from `results/figures/`, and final evidence from the frozen test output. Choose the actual run paths in use rather than assuming these example names exist.

Each figure includes a `.source.json` sidecar and the figure directory contains exact numeric inputs and a checksum manifest. Preserve these files when selecting illustrations. Fixture charts carry an artificial label and must not appear as study findings.

Use the [report outline](../docs/project-plan.md#report-outline-and-evidence-map) and [manual sequence](../docs/manual-steps.md). The agent can check the final PDF and code archive after you supply the manuscript. Course PDFs and generated study PDFs remain outside Git.
